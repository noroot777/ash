# 排队输入折叠 Demo

入口：`pending-input-demo.html`。同目录的 CSS、JS 和 HTML 一起保留，直接用浏览器打开即可；没有构建步骤、外部依赖或真实任务请求。

## 方案

- 0 条隐藏等待区，1–2 条直接展示。
- 超过 2 条展示一张叠层卡片：总数、来源统计、前两条预览及剩余条数。10 条和 30 条占用相同高度。
- 完整列表向上浮出，列表内部滚动；展开不会移动或覆盖输入框，Esc 或点击外部可收起。
- 「需留意」展示示例中退出码非 0 的输入，不等同于整个任务失败。
- 筛选保留原始队列序号，不合并内容或调整顺序；没有批量清空入口。
- 哨兵输入的取消操作有确认，并明确只取消本次唤醒、不停止哨兵。个人消息支持模拟撤回和引导会话，撤回保留现有草稿。

顶部可切换原来 / 推荐方案、0 / 1 / 2 / 10 / 30 条、混合消息，并模拟新输入与按顺序处理。

「原来」是为比较空间占用制作的静态模拟，不是正式组件的完整复刻。所有消息、退出码及操作反馈均为演示数据；本次未修改正式组件或后端逻辑。

## 验证记录

2026-10-24，以独立无头 Playwright 浏览器验证：

- 0 / 1 / 2 / 3 条折叠边界及处理至空队列。
- 10 / 30 条固定高度、完整列表与来源 / 需留意筛选、原始顺序。
- 新输入到达时保留展开的正文和列表滚动位置。
- 取消确认、确认后再次按 Esc 不误取消、撤回时保留草稿、仅最早个人消息可引导会话。
- 消息内容按文本转义、无外部请求、无浏览器运行错误、减少动态效果偏好。
- 1440 / 1024 / 768 / 390 / 320 px 五档宽度无横向溢出，浮层头部完整且不覆盖输入框。

执行命令：`sh output/playwright/run-pending-input-checks.sh`，工作目录为任务 worktree。ash 回归记录 `ibX06R0Ltt5L`，退出码 0；检查脚本包含逐项断言，已核对日志及桌面、移动端截图。测试脚本和截图位于本轮工作目录的 `output/playwright/`，未纳入产品源码提交。
