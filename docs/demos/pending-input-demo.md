# 排队输入折叠 Demo

入口：`pending-input-demo.html`。同目录的 CSS、JS 和 HTML 一起保留，直接用浏览器打开即可；没有构建步骤、外部依赖或真实任务请求。

## 方案

- 0 条隐藏等待区，1–2 条直接展示。
- 超过 2 条展示一张叠层卡片：总数、来源统计、前两条预览及剩余条数。10 条和 30 条占用相同高度。
- 同一张卡片原位向上展开完整列表，底边与输入框位置保持不变；收起时的两条预览由完整列表替换，不再另开浮层或重复展示队列。
- 展开列表内部滚动；点卡片上的「收起列表」或按 Esc 恢复，点击输入框不自动折叠。
- 「需留意」展示示例中退出码非 0 的输入，不等同于整个任务失败。
- 筛选保留原始队列序号，不合并内容或调整顺序；没有批量清空入口。
- 哨兵输入的取消操作有确认，并明确只取消本次唤醒、不停止哨兵。个人消息支持模拟撤回和引导会话，撤回保留现有草稿。

顶部可切换原来 / 推荐方案、0 / 1 / 2 / 10 / 30 条、混合消息，并模拟新输入与按顺序处理。

「原来」是为比较空间占用制作的静态模拟，不是正式组件的完整复刻。所有消息、退出码及操作反馈均为演示数据；本次未修改正式组件或后端逻辑。
