常用命令 / 项目级运行现场放哪儿 —— 四个方案

背景：启动 / 停止 / 重启常驻命令是项目级的事，塞进任务 inspector 或压在任务下面的终端抽屉都不对。 四个 demo 全部可点：启动会变停止、徽标会联动、面板会弹。视觉按现有 web 风格仿制，交互是假的、纯前端。

方案 A · 传统 · 推荐起点

项目主页

没选任务时，主区就是项目自己的屏幕：服务卡片、git 概览、全尺寸终端。服务跑在终端 tab 里，日志白捡。

 方案 B · 传统+

全局状态栏

VS Code 式一条 app 级状态栏横贯底部：分支、运行中 N、终端入口。任务区一点不动，任何时候一眼可见。

 方案 C · 大胆

树里的第二实体

服务长进任务树：项目下固定一节「运行」，点服务行主区就是它的现场（全屏日志 + 启停重启 + 就地配置）。

 方案 D · 远期

跨项目运行中心

「现在到底有什么在跑」的一张总图：所有项目的常驻服务、预览、终端、agent，外加 ash 管不到的旁路会话上报。

A 与 C 互补（主页做现场、树做入口），B 可叠加在任何方案上当常显徽标，D 可以以后长在 A/C 之上。
