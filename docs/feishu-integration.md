# 飞书接入与使用

飞书是 ash 的遥控器和决策收件箱。通道内置在 ash server 中，通过企业自建应用机器人的长连接收发消息，不需要开放公网回调端口。长会话、diff 审阅和预览仍在 ash 网页查看。

## 开通与绑定

1. 在飞书开发者后台创建企业自建应用并启用机器人。长连接是集群模式，同一应用的多个客户端不会各收到一份事件；不同 ash 实例各用一个应用。
2. 在 ash 的「设置 → 飞书」保存 App ID 和 App Secret，等待状态显示「已连接」。
3. 在飞书后台选择长连接，订阅事件 `im.message.receive_v1` 和卡片回调 `card.action.trigger`。
4. 开通单聊读取 `im:message.p2p_msg:readonly`、机器人发消息 `im:message:send_as_bot`；使用群聊时再开 `im:message.group_at_msg:readonly`，接收图片和文件时再开 `im:resource`。
5. 发布应用版本。权限和订阅每次改动后都需要重新发布，部分权限需要企业管理员审核。
6. 在已登录的 ash 网页生成绑定码，在机器人单聊中发送，再回网页确认绑定申请。绑定码十分钟有效，不经飞书传输 ash 访问密钥。

绑定按应用与飞书用户身份记录，换应用后重新绑定；停用 ash 用户会使绑定失效。自用模式只绑定机主一个人，群功能默认关闭。群聊通过网页绑定项目，只接收群里 @ 机器人的消息，不读取群内全部对话。

设置页可配置总开关、完成通知、ash 深链地址、月额度和「只推标题」。深链地址使用手机能访问的 ash 地址；卡片按钮本身不依赖手机已登录 ash 网页。

## 收消息与发指令

- 单聊普通文本进入个人助手房间；已绑定项目的群消息进入项目群聊。
- 直接回复提问卡就是答复，图片和文件可随答复送入任务。同一道题再次出现时，旧卡上的回复不会答中新问题。
- 回复其他任务卡时，以 `/reply` 开头才向任务发消息，避免误把闲聊当成答题或续跑要求。
- `/todo` 查看待处理事项并继续领取积压卡片；积压超过五张时先显示汇总卡，每次释放五张。
- `/tasks` 先选项目再看任务，`/tasks 项目名` 直接查看指定项目；飞书里没有全局「当前项目」。
- `/new` 打开建任务表单，选择项目并确认后才创建；命令后的文字和附件会随表单保留。
- 回复任务卡发送 `/stop` 会先显示确认卡；回复失败卡发送 `/retry` 可重试。
- `/help` 显示机器人命令说明。

任务提问、待验收、失败、审查争议和 duet 闸口可以通过卡片处理。团队执行者的问题仍交给调度台，只推调度台自己的提问。任务在网页或手机上处理后，旧卡片会同步收起或更新。

自用模式的新设备配对申请也可发到机主单聊，允许时有二次确认；申请到期、已在别处处理或 ash 重启后，旧卡失效。设备名册和长期访问凭据仍在 ash 页面管理。

## 权限与安全

飞书动作以绑定用户的 `im` 身份进入 ash 路由，受项目可见性和动作白名单限制，不等于完整账号权限或实例管理员。按钮同时校验收件人、有效期、使用状态及当前事项版本，失效按钮不能重新授权一次操作。

以下动作不提供飞书按钮：

- `reclaim-turn`、`kill-cua`、删除会话消息等真人保护操作。
- 强制通过验证；它可能继续推进合并，不可逆，自由工作流下也不支持。
- 跳过验收前置命令，或强制确认未经独立验证的成果。

`stage=verify_failed` 只发通知、不提供强制通过按钮；预设工作流停在「人工」站点时目前不推决策卡。

飞书账号是控制本机任务的一种凭据；企业管理员和应用协作者能够改应用配置及轮换密钥。应用权限仅覆盖实际使用的消息和附件功能，不需要通讯录、文档或群全部消息权限。消息正文不作为身份或授权依据。

App Secret 保存在数据库旁的 `<db>.feishu.json` 中，不进入数据库设置、环境变量或预览快照。macOS/Linux 文件权限为 0600；Windows 取决于所在目录的权限。同一 OS 用户下运行的 agent 仍可能读取这个文件，这不是 OS 级隔离。

## 状态与排障

连接状态和错误原因显示在设置页及 `/api/health`。ash server 停止或事件循环卡死时，机器人也会离线；未配置凭证和预览实例不启动通道。

出站通知根据数据库对账，另有十分钟一次的全量核对。失败操作会恢复可重试按钮并显示原因；长连接中丢失的按钮点击可重新点击。网页解绑或失去项目权限后，不继续把原项目内容发给旧绑定。

卡片输入框最多 1000 字，长答复直接回复提问卡。卡片不推会话流式正文，避免把代码和敏感内容复制到 ash 无法撤回的外部历史；「只推标题」限制通知和操作结果，不限制用户主动发问后的助手或群聊回复。

月额度在设置页可调整，默认一万次；每次调用按用途记账，按北京时间切月。用量达到 70% 时不再添加收件表情，90% 时仅保留决策卡、对话回复、附件下载和结果回写，99% 时只保留操作结果回写。设置页可查看本月用量与分类明细。
