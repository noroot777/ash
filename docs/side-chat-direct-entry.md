# 侧聊直接提问

2026-09-14，选文功能的交互更新。

选文后的「在侧聊中提问」、主任务顶栏入口、Inspector 的「侧聊」页签使用同一个输入区。打开后可直接填写问题，已有侧聊会恢复记录与草稿；不再经过执行器配置页或「开始侧聊」按钮，也不再在消息区显示欢迎说明。

引用卡紧贴输入框上方，长引用可展开、收起或滚动查看，完整原文不裁切，也可移除。输入框底部使用现有三段控件调整智能体、模型和智能水平。新草稿默认沿用主任务配置，用户调整后的新草稿配置会在本地保留。历史房间继续使用自己的已保存配置。

打开面板、选文、输入问题、修改新草稿的模型都不会创建房间或调用侧聊模型。第一次发送才依次创建房间、提交消息；「新建侧聊」也先打开新草稿。创建时冻结主会话快照，后续变化不会自动倒灌，选文仍可单独补充背景。

新草稿的问题与引用按主任务暂存，已有房间的草稿按房间保存。创建失败保留完整草稿并复用房间编号重试；创建成功但消息发送失败时保留该房间，重试沿用消息编号。创建期间继续输入的新问题和选文不会被旧请求的回执清掉。关闭重开、刷新、切换房间与任务均保留相应草稿。

已有侧聊的模型调整直接保存；连续选择模型和智能水平时按顺序写回。保存期间或保存失败、配置尚未确认时，按钮和 Enter 都不能发送。失败显示原因，重新连接后读取服务端实际配置，也可重新选择。迟到的旧快照不会覆盖刚保存的模型。

容量、历史整理和回传用法放在默认收起的「侧聊说明」中。引用加问题仍限 8000 字，超限时原文保留且不创建房间、不发送；主会话快照仍限 64 KiB，在首次发送时检查并就地显示错误。
