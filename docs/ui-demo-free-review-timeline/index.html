为什么把第二次“任务执行”画回来

这里展示的是事实日志，不是预设流程。相同名称的两次审查之间只要发生过续聊修改，那次执行就是理解因果关系的关键节点，不能被审查摘要吞掉。

为什么审查详情按“次”收起

列表摘要保留时间、状态和检查类型；报告、截图、秒级耗时只在点开后出现。长任务的默认高度因此只随事件条数线性增长，不会被长报告放大。

交互试法

点“第 1 次审查”查看完整报告，再点同一行收起；点“第 2 次审查”会自动收起上一条。正在运行的时间线图标与状态点会持续转圈。
