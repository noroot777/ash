你想让它多稳？

拖一下。左边是「干完就算完」，右边是「你点头它自己合并」—— 流程会跟着长出来，你不用先学会「关口」「失败去向」这些词。 拖到顺眼为止，剩下的两个问题各是一个开关。

快稳
为什么先给一个旋钮

绝大多数人心里只有一句话：「这活我要盯多紧」。旋钮把这句话直接变成控件， 五档之间的差别是看得见的——线变长、多一个圆点、打扰次数那行数字跟着变。 没人需要在第一屏理解六种关口。

要编排的人也没被挡住

「再细一点」是折起来的第二层：展开才有每一站的参数、加站、失败去向。 第一次用的人一眼看不到它们，用久了的人一次点击就到。不是砍掉能力，是把能力叠起来。
