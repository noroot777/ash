一个任务干完要过哪几关 —— 三种编辑方式，挑一个顺眼的

三个页签是同一份工作流的三种壳子：随便在哪一种里改，切过去另一种就是改完的样子。 都能加步骤、删步骤、换顺序、插自定义命令、把失败指到任意一步。模板只是起手式，不是选项。
上一版（固定主干 + 一排开关，只能改参数不能改结构）留在 ../ui-demo-workflow-claude/index.html 可对比。 同样这套编排能力、视觉上另外两副外观：深色调度台 · 暖纸底线路图 · 可拖拽工作台（带预演） · 线路图 · 能跑一趟 · 一个旋钮 · 照着刚跑完的那次改 · 融进新建任务。

为什么不是画布

一个任务的关卡链几乎总是一条线，偶尔往回拐一下。给一条线配一张可以随便摆位置的画布， 用户要先学会连线、对齐、找节点，才能表达一件本来一句话就说清的事。

真正需要图的是任务之间的先后 —— 那是分组和队列的地盘，工作流一个字都不碰。

放开编排的前提是有闸

能自己排，就必然排得出坏流程：合并前没人看、预览起了没人关、失败往前跳成死循环。 所以底下那条编译结果不是装饰 —— 红的就存不下去，并且告诉你是哪一步、为什么。

这些判断在保存时做一遍，任务开跑前再做一遍，改不动的旧任务用当时的快照。

存的是同一份东西

三种壳子共用一份定义：一串步骤 + 每步的参数 + 每步失败的去向。 句子式适合配置和复核，清单式适合改结构，表格适合一眼扫完一条长流程。

页签是视图偏好，不是三套功能，也不需要用户先选对一个。
