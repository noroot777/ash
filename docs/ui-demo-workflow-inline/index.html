为什么它挤得进去

整条线收起来的时候只剩站名：一排小胶囊 + 中间常驻的虚线 ＋。 高度和「执行模式」那一节的一行下拉框一样。参数、任务显示什么状态、失败往哪拐， 全部挪到点开哪一站才出现——你不点，它就不占地方。

要真编排的时候再长大

右上角「展开编排」把同一条线撑开成 线路图那副样子：站台、参数、失败支线都在。 同一份定义、同一套操作，只是两个尺寸。设置页里放的就是展开态。

三层作用域在这儿只是一句话

新建任务时它默认跟着项目走，标题旁边那颗小标签就是来源。 你在这儿动一下，它自动变成「这个任务自己定」，并给你一句 「存成本项目以后的默认」——继承关系不用先学，改了才需要知道。
