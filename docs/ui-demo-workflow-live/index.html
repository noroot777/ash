    ② 任务列表里 —— 不画图，只留一根进度条

    为什么放 Inspector，而不是顶在详情页头上

    详情页的正中间是会话——你大部分时间在那儿看输出、发指令，任何横条压在它头上都是在抢地方， 而且滚两屏就看不见了。Inspector 是常驻右栏，整条线一直在眼角， 又不占会话一行。它本来就是「关于这个任务的边栏信息」该待的地方，和「信息」「审查」两个页签并排。

    竖过来不是妥协，是升级

    横着排，每一站头顶上只塞得下两三个字；竖过来每一站有一整行的宽度： 参数摘要（gpt-5.6-sol · xhigh）、这一关跑了多久、没过的话为什么没过，全能写全。 最要紧的是——轮到人工关口时，「通过 / 打回」直接长在那一站底下， 不用再翻到别处找按钮。往回拐的那一轮画成左侧一道琥珀色的括号，圈住要重来的几站。

    列表里必须退化成一根条

    列表一屏几十行，每行塞张图必死。所以那里只保留五个色段 + 一个状态词—— 色段数 = 站数，亮到第几段就是走到第几站， 和 Inspector 里显示的是同一个词（「需你处理」就是「需你处理」）。 新建任务里的收起态用的是同一套退化规则。
