为什么入口在这儿

没人是先想清一条流程再去建任务的。真实的顺序永远是：跑了一次， 觉得「这儿不该直接合并」「这儿我想先点开看看」——不满意是具体的， 那就让他在具体的地方说，而不是丢给他一张空白的编辑器。
