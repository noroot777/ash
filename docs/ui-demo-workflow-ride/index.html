线路 · 单个任务

一条线，按一下就能看它怎么跑。

每一站是一道关口。改哪儿点哪儿——点参数就地换、点段中间加一站、点失败标签改去向， 全程不用选中、不用去别处的面板找。摆完先跑一趟：车沿线走一遍， 每停一站就显示那一刻任务在列表里是什么状态，失败了就顺着支线倒回去重来。

改哪儿点哪儿

参数就写在站台底下，点一下弹出的只有这一个字段的几个选项，点完即关。 没有「先选中、再去右边面板、再找到那一行」这三步——一条几站的线，绝大多数改动是一次点击。

状态不是跑起来才知道

每一站底下常驻一行「任务显示：需你处理」，这就是这条流程走到那一步时， 任务列表里那一格写的字。按跑一趟能看它按时间依次亮起来，失败时车会沿虚线支线倒回上游。

系统 / 项目 / 任务三层

上面那排是作用域。项目和任务默认继承上一层，只有你真动了才分出自己的一份， 随时能恢复继承。同一份定义的其它外观：纯线路图、 深色调度台、 句子 / 清单 / 规则表、 一个旋钮、照着刚跑完的那次改。
