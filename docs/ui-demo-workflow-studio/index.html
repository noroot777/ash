一个任务干完要过哪几关 拖着排、键盘敲、预演一遍再存

这一版补的是「能不能上手摆」，不是配色。 左边关口库拖进轨道、卡片之间拖着换顺序、从关口右侧小圆点拉一条线到上游任意一关就是「失败后回那里重做」； 全套还有键盘路径（↑↓ 选、⌘↑↓ 挪、⌫ 删、⌘K 什么都能搜）； 存之前可以预演：假设哪几关不过，看这条流程会怎么走、每一刻任务显示什么状态、最多打扰你几次。

交互取自：Zapier 的常驻侧栏检查器（改参数时整条流程不被挡住）· Apple 快捷指令的拖拽排序与就地撤销 · GitLab pipeline editor 的 dry-run（只做 lint 会给人「已经验证过」的错觉）· Raycast/Linear 的 ⌘K 与「回车即主操作」· n8n 的执行状态（含 waiting）与人工关口作为一等节点 · Azure Logic Apps 的「仍然保存」（提醒不等于拦死）。
