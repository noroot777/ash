「起手式」不是系统写死的五个格子，是一个你自己维护的库。 新建、复制、改名、删除都在这儿；系统自带的那几个也照样能改——改完它就带上「已改过」， 旁边永远留着一个「恢复系统默认」，所以改坏了不心疼。系统自带的删不掉，但可以停用： 从新建任务的菜单里消失，需要时再恢复。

起手式
系统自带的怎么改：覆写 + 永远能恢复

改系统自带的那几个，不会偷偷给你复制出一份副本——你改的就是它本身，名字还叫「标准交付」， 所有从它起手的新任务立刻用新的。代价只有一个标记：「已改过」， 以及一个随时可以按的「恢复系统默认」。删除对系统自带的降级成停用， 因为「删掉之后再也拿不回来」对一个内置物件来说是假承诺。

改起手式，不会追着改已有任务

任务在创建那一刻就把线拷了一份进自己兜里，之后它跟起手式再无瓜葛。 所以你随便改起手式，正在跑的 12 个任务不会被你改成另一副样子—— 这也是为什么它叫「起手式」而不是「模板引用」。 右下角那句「14 个任务从它起手」是历史统计，不是绑定关系。

三个来源，都能变成一个起手式

新建时给三条路：空白从一站开始搭；复制一份拿现成的改； 最顺手的是第三条——从某个任务当下的线存过来： 你在新建任务里为了这一次改出来的那条线， 改完发现好用，一键存成起手式，下次直接挑。
