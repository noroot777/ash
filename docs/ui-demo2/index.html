决定一:单一侧边栏,四栏变三栏

旧稿最左边是个专职项目窄栏(一个导航项 + 大片空白),信息密度太低。现在项目切换器和全部导航收进一条 240px 侧边栏;它是全局壳,右边整块随导航项换页:选「任务」= 任务列表 + 会话正文 + Inspector 三栏,选其它 = 对应全页面。

240px · 全局常驻单一侧边栏顶:项目切换器(头像+名+▾,下拉带搜索/齿轮/新建);中:任务(计数)/智能体/分组/已归档/项目设置/随手记;底:搜索 ⌘K / 连接状态 / 收起
264px · 任务页① 任务列表头:分支 chip + 新建;身:协作任务与普通任务按状态分段,团队行可展开执行者。分组/归档/随手记入口移去侧边栏,头部不再挤图标
自适应 · 任务页② 主工作区44px 头栏(类型 chip · 标题 · 状态 pill · 高频动作),下面按任务类型切换:会话 / 调度流 / 辩论 / diff / 新建面板
306px · 任务页③ Inspector属性、执行信息、队列(点开右侧抽屉)、审查轮次、prompt 原文;团队页与执行者栏合并为带 tab 的右栏;▥ 一键收起

侧边栏「任务」项的选中态吃的就是全局方案——切 S1/S2/S3,侧边栏、任务列表、下拉、⌘K 一起变。

决定二:弹窗 → 页面 / 抽屉,对照清单

判据:要「沉浸编辑或浏览一批东西」的去页面;要「就着当前上下文看一眼」的用侧滑抽屉;只有「快速一击」(⌘K)和「随时随地记一笔」(随手记)保留弹层。删除确认这类小 confirm 不在本次演示范围。
