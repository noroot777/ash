Linear 设计语言摘要

这不是形容词清单，而是本轮重画 harness 特有组件时实际执行的约束。每一条都能直接落到 CSS 或版式判断。

01 / 表面无彩表面，亮度差代替粗边框

侧栏固定在 RGB 239/239/240，主内容固定在 249/249/250，白色只给输入、菜单和局部浮层。大块区域不使用抬升层或覆盖层。

02 / 节奏4/8px 节奏，28/32/44px 控件带

行高与间距从 4px 倍数取值；侧栏行 28px、菜单项 32px、任务行 44px。信息密度靠节奏，不靠把字号压小。

03 / 字体字重和亮度承担层级

正文 13px/400–500；标题只升到 500–600。一级信息接近黑，说明用 L39，时间和快捷键用 L64，不用额外色块分组。

04 / 状态状态色只落在微点与细图标

绿色、琥珀、青色、红色只用于 6–8px 状态点、勾叉或短文字；不再给整张执行者卡、审查报告或会话气泡铺色。

05 / 深度阴影分三档，边框只做校准线

控件用 1px 淡内环 + 两层微阴影；菜单用三层短阴影；命令面板才使用长阴影。普通内容区不加“卡片感”。

06 / 动效150ms，短促且可逆

悬停、聚焦、开关统一 150ms，常用缓出；按下只回落背景或阴影，不缩放跳动。详情栏的结构动画保持 180ms。

施工映射：任务树学习侧栏团队展开；调度流学习活动记录；执行者栏学习任务列表；甘特学习时间线；验收与审查学习清单和活动；会话和辩论学习任务评论流。
