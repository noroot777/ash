两个此前没答案的问题

Q1 项目信息放哪、怎么切换?

项目就住在左上角那一个控件里。

项目栏顶部是「头像 + 项目名 + ▾」,点开即下拉:当前项目(带仓库路径和设置齿轮)、搜索框、「切换到」列表、底部新建项目。切换项目的所有入口收敛到这一处,⌘K 里保留「切换项目」命令作为键盘快路。

下拉里的当前项高亮吃的正是选中态方案——去 01 主视图(默认开着下拉)切 S1/S2/S3 看效果。

Q2 团队页右侧两个栏怎么共存?

合并为一个带 tab 的右栏。

WorkerRail 和 Inspector 都天然住右侧,叠两栏太挤、浮层互踩。方案:右栏顶部两个 tab——「执行者」(默认,卡片列表,点卡片弹全宽抽屉看该执行者完整会话)和「详情」(团队属性/统计/审查)。▥ 按钮整栏收起。

时间轴不再常驻:收成头栏下的一行摘要,点开才展开甘特图。见 03 团队调度台。
