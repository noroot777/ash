## 侧栏 / 项目与任务树

| 缺什么 | 现行行为是什么 | 建议优先级 |
|---|---|---|
| 项目切换器内缺少直接的新建项目入口 | 旧版项目栏可直接新建项目；新版主要依赖 ⌘K 的“新建项目”，首次使用时不够可发现 | P2 |

已核对：团队/辩论/普通任务的层级、状态、执行者计数与同一数据库一致；新侧栏把这些数据重新分区不属于缺陷。

## 单任务详情

| 缺什么 | 现行行为是什么 | 建议优先级 |
|---|---|---|
| 只能查看定时配置，不能新增、修改或清除单次/Cron 调度 | 旧版详情页提供完整的定时控制，并复用服务端现有 `setSchedule` / `clearSchedule` 语义 | P1 |
| 缺少手动派审查入口 | 旧版允许任务完成后手动选择审查执行器、模型和思考强度补派审查；新版 API 层已有 `dispatchTaskReview`，但 UI 没有调用 | P1 |
| 删除任务的 Git 清理失败后不能在新版二次确认强制清理 | 旧版会展示 git stderr，并提供显式的 `--force / -D` 第二步；新版只能提示改用旧版 | P2 |
| 派生任务/团队执行者缺少显式的来源或父团队返回条 | 旧版在详情上方展示来源任务、父团队或来源辩论的可点击关系；新版只在侧栏嵌套和只读提示中间接表达 | P2 |

已核对：标题、状态、优先级、分组、标签、执行器/模型/思考强度、队列、会话、附件、提问答复、运行/停止/重试、归档和普通验收入口均能落到真实 API。

## 团队调度台

| 缺什么 | 现行行为是什么 | 建议优先级 |
|---|---|---|
| 暂无独立的新缺口；完整团队 diff 见下一节 | 新版的时间轴、调度流、执行者 rail/抽屉、停止/恢复全组、持久停止提示、答复和 CUA 残留提示均已接通 | — |

视觉取舍：新版默认折叠时间轴、把执行者放右 rail，和旧版默认展开大时间轴不同；这不改变现行功能语义，不算缺陷。

## 验收（单任务 + 团队）

| 缺什么 | 现行行为是什么 | 建议优先级 |
|---|---|---|
| 团队验收只列前 8 个改动文件，完整 diff 必须回旧版 | 旧版团队验收台可展开全部文件和逐行 diff；新版目前只给提交摘要、文件统计和前 8 个文件 | P1 |
| 单任务验收没有从页面补派审查的操作 | 旧版验收区可在没有审查记录时手动派审；新版只显示已有审查证据和空态 | P1 |

已核对：独立 worktree 单任务可显示源分支、目标分支、比较基点、提交、文件树和逐行 diff；共享团队执行者不会再伪造独立分支或提供必然 409 的单独验收按钮，而是引导到父团队统一验收。

|---|---|---|
| 缺少定时设置 | 旧版辩论页可设置单次/Cron 调度；新版只展示并运行即时辩论 | P2 |

## 设置

| 缺什么 | 现行行为是什么 | 建议优先级 |

## 新建任务

| 缺什么 | 现行行为是什么 | 建议优先级 |
|---|---|---|
| 缺少单次/Cron 的“创建后定时运行”模式 | 旧版底部可在仅创建、立即运行、单次和 Cron 之间选择；新版只有“仅创建 / 创建并运行” | P1 |
| 缺少标签编辑 | 旧版新建时可添加多个标签，创建请求直接持久化；新版只能设置优先级和分组 | P2 |
| 缺少“再建一个”连续录入 | 旧版创建后可保留面板连续建多张任务；新版创建后直接进入新任务 | P3 |
| 分组下拉不能就地新建分组 | 旧版可从分组选择器进入新建分组；新版需要先离开表单去设置或 ⌘K 新建 | P3 |

已核对：单任务/团队/辩论三种模式、执行器 Profile、模型与思考强度、团队审查者、辩论轮数/G1、worktree/base、附件、优先级和斜杠切换均接真实创建 API。单任务、调度者、执行者和审查者切换执行器时都会清空旧执行器的模型/思考强度覆盖，避免跨 CLI 静默错配。

## 新旧版逃生门

本轮已补齐页面上下文参数，不再只携带项目/任务：

- `view=review`：单任务或团队验收台；
- `view=settings&settings=project|groups|archive|providers|executors|modes|defaults`：设置分节；旧值 `agents` 兼容跳到 `executors`；
- `view=palette`：⌘K；
- `view=notes[&note=…]`：随手记及当前条目；
- `view=create&mode=single|team|debate`：新建页和模式。

新版到 `/legacy/`、旧版到 `/` 都保留 `project` / `task` 及上述上下文。弹层和新建页额外提供浮动逃生门，避免底层链接被遮罩拦住；验收页使用页内链接原位跳转。

动态切换新建模式（页签或 `/single`、`/team`、`/debate`）会同步更新地址栏和浮动逃生门的 `mode`，不只保证直接构造深链时的初始落位。
