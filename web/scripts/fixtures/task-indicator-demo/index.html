NAVI / 第二轮交互方案对照

看过归看过，验收归验收。

三种常驻表达，同一批任务。点开只表示看过，验收状态不会跟着消失；标题的字重和颜色始终一致。

01只给已验收一个勾

完成任务里，没勾就是未验收。只有真正验收后，行尾才出现一个灰色小勾。

无勾 = 待验收 · 灰勾 = 已验收

02用一层浅底色区分

未验收的完成任务保留浅底色，验收后恢复普通背景。选中另用细边框表达。

浅底色 = 待验收 · 普通背景 = 已验收

03明确的验收框

空框表示还没验收，打勾表示已验收。点空框进入模拟确认，点标题只查看任务。

空框 = 待验收 · 勾选框 = 已验收

先试“过会儿再回来”清掉新结果提示和选中状态，再检查：哪几条还没验收？三版的常驻表达都会留下。

再试“验收”在详情中模拟验收，或点方案 3 的空框。确认后，三版分别出现灰勾、清除底色、勾上验收框。

本页仅使用模拟数据，不会读取或修改真实任务。
